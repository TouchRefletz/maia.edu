# Telas de Administração e Auditoria (`docs/ui/admin-modals-screens.md`)

Documentação das telas administrativas, modais de verificação de questões e relatórios visuais.

---

## 🖥️ Telas e Modais Mapeados

- **`admin-panel.js`**: Painel administrativo para governança, moderação de questões e métricas globais do Firebase.
- **`apendice-a-screen.js` & `apendice-b-screen.js`**: Interfaces visuais para acompanhamento de benchmarks e experimentos científicos de IA.
- **`verificar-questoes-screen.tsx`**: Tela de auditoria para comparar a questão extraída pela IA com a imagem original escaneada.
- **`TextAuditModal.tsx`**: Modal de inspeção e edição de inconsistências textuais em enunciados.
- **`ScanOriginalModal.tsx`**: Modal de zoom e visualização do recorte de prova físico original.
